# 11. Process Logging and Hull-Cell Testing

## Process log

A useful batch log contains:

  Field             Record
  ----------------- ---------------------------------------------
  Date/time         Start and finish
  Operator          Name/initials
  Part/load         ID and quantity
  Substrate         Alloy/material
  Exposed area      ft² or dm²
  Current           A
  Current density   A/ft²
  Time              min
  Ampere-hours      Ah
  Temperature       Start/end
  pH                Start/end
  Additions         Product, lot, amount per supplier procedure
  Appearance        Brightness/color/defects
  Thickness         Measured result
  Notes             Changes or abnormalities

## Hull-cell testing

A Hull cell is a small electroplating test cell with angled cathode
geometry that exposes a panel to a range of current densities in one
test.

It can help distinguish:

-   Low-current-density weakness
-   High-current-density burning
-   Brightness-range changes
-   Some contamination patterns
-   Effects of approved additive adjustments

## Good Hull-cell discipline

1.  Use clean, consistent panels.
2.  Use a representative bath sample.
3.  Control temperature.
4.  Use consistent test current and time.
5.  Prepare panels identically.
6.  Label every panel.
7.  Compare with a known-good reference panel.
8.  Make only controlled changes.
9.  Record the result.

A Hull cell is most powerful when used comparatively. One unexplained
panel is less useful than a history of panels tied to bath records.
